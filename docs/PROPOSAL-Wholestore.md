# Proposal：Wholestore

**面向厂家与经销商的 B2B 下单、履约与结算门户**  
**日期**：2026-09-06  
**状态**：客户讨论稿  
**商务标准**：开发部署 **USD 8,000**（一次性）+ 上线后 **USD 200 / 月**

产品界面文案使用 English（Vendor / Dealer / Shop / Order / Invoice / Tracking）。本文为商务说明，使用中文。

---

## 1. 产品一句话

经销商在 Wholestore 看专属价、下单、查物流与账单；厂家审核客户、维护价盘、处理订单，发货时把运单绑到订单。库存仍在客户 ERP，发票仍在 QuickBooks Online，门户不做第二套账本。

首期范围：**一家 Vendor（厂家）+ 其多家 Dealer（经销商）**。

---

## 2. 平台怎么落地

按 Adaven Platform 规范单独部署，不与其它产品共用登录。

| 项 | 约定 |
|---|---|
| 组织 | 底层两种空间：Vendor（供货）/ Dealer（采购） |
| 账号 | 本产品独立账号；每家组织可有多名成员（Admin / Member；仓管可只开通发货） |
| 端 | **Web**：入驻、定价、下单、订单、账单。**Mobile**：查单、查轨迹、仓库扫码绑运单 |
| 托管 | 独立数据库 + Web 站点；上线后由月费覆盖 |
| 外部系统 | ERP（默认 Finale Inventory）管库存与履约单；QuickBooks Online 管发票与应收；承运商管轨迹 |

```
Dealer Web / App          Vendor Web / 仓库扫码
        \                      /
              Wholestore 门户
               |        |
           客户 ERP   QuickBooks Online
               |
           承运商轨迹
```

## 3. 计划功能模块

以下为本次报价覆盖的交付模块。每条只写业务结果，不展开页面清单。

### M1 账号与组织 — $800

登录、注册、重置密码、邀请加入、切换当前 Vendor / Dealer。厂家与经销商各自维护本组织成员。未登录不能进入业务功能。

### M2 经销商网络 — $1,000

经销商提交企业资料；厂家审核通过后才开放下单。厂家可停用某经销商、绑定账期与价盘。经销商维护本公司资料与采购成员。

### M3 商品、价盘与选购 — $1,400

SKU 与库存以 ERP 为准，门户同步展示，不在门户新建库存账。厂家维护价盘（客户价、MOQ、整箱规则）并分配给经销商。经销商只看到自己的价，走 Shop → Cart → Checkout，可填 PO# 后下单。

### M4 订单与履约 — $1,200

双方查看同一张门户订单。提交后写入 ERP **一张**销售订单；失败可重试，不得开出第二张。状态对用户为：Submitted / In fulfillment / Partially shipped / Shipped / Invoiced。

### M5 发货与物流 — $1,200

仓管扫面单或手工录入，把跟踪号绑到订单（一单可多运单；同一跟踪号不能绑第二单）。厂家与对应经销商在同一订单上看轨迹。绑错可解绑后重绑。

### M6 账单与账期 — $1,000

经销商看账期（如 Net 30）、应付合计与逾期。Invoice 只读，来自 QuickBooks Online，门户不另开一张票、不做在线支付。

### M7 连接、品牌与上线 — $1,400

接通 ERP / QBO / 2–3 家承运商轨迹；配置 Logo 与门户域名；导入首批经销商与价盘；陪跑验收并切到生产。

| M1 账号与组织 | $800 | 10% |
| M2 经销商网络 | $1,000 | 12.5% |
| M3 商品、价盘与选购 | $1,400 | 17.5% |
| M4 订单与履约 | $1,200 | 15% |
| M5 发货与物流 | $1,200 | 15% |

## 4. 首期不做

- 退货、Credit Memo、EDI、多币种、在线收款  
- 自动授信、多级采购审批、催款工作流  
- 多厂家公开市场、QuickBooks Desktop  
- 自建仓库 / 承运商运力  
- 第二套 ERP 或第 4 家及以后承运商（需另报）

## 5. 交付节奏

客户授权与主数据齐备后，日历约 **7–8 周**。

| 阶段 | 周次 | 结果 |
|---|---|---|
| 启动 | 第 1 周 | 账号组织可用；品牌与管理员就位；外部系统版本锁定 |
| 主路径 | 第 2–5 周 | 入驻 → 定价 → 下单 → 订单写入 ERP，可演示 |
| 履约与账 | 第 6–7 周 | 扫码绑运单、轨迹、Invoice 只读可打开 |
| 上线 | 第 8 周 | 生产域名、首批经销商导入、验收签字 |

卡住点通常是客户侧授权，不是模块本身。授权未齐备时对应阶段顺延。

## 9. 验收主路径

1. Shop 能看到 ERP 中的可售商品与客户价。  
2. 经销商入驻通过后可下单；订单上出现 **一个** ERP 单号。  
3. 扫码或补录后，订单上出现运单；双方看到同一轨迹。  
4. 对应 **一张** QBO 发票可打开。  
5. 同一单再次提交、同一跟踪号再绑：不得出现第二张 ERP 单或第二张发票。
